# Wireless Access Point Password Auditing (WPA/WPA2)

**Domain:** Ethical Hacking  
**Simulator:** [`lab10_wireless_simulator.html`](./lab10_wireless_simulator.html)

## Overview & Methodology
Demonstrates WPA/WPA2 4-way EAPOL handshake capture (`airmon-ng`, `airodump-ng`), deauthentication frame injection (`aireplay-ng`), and offline dictionary/PSK auditing (`aircrack-ng`), accompanied by an interactive wireless auditing simulator ([`lab10_wireless_simulator.html`](./lab10_wireless_simulator.html)).
